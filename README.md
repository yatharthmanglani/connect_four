# Connect Four

A simple command-line implementation of Connect Four in Python.

## Current version

Phase 1 - Human vs Computer(Random move)

## Rules

- The board has 6 rows and 7 columns.
- Players take turns dropping pieces into columns.
- A piece falls to the lowest available position.
- The first player to connect four pieces horizontally,
  vertically, or diagonally wins.
- If the board is full and nobody wins, the game is a draw.
